
# Inventory & Supplier Management System

## 1. Project Objective
To develop a database system that manages products,
suppliers, purchase orders, and stock movements.

## 2. Technology Stack
- Primary Database: MySQL 8.0
- Secondary Database: MongoDB
- Backend: Python Flask
- Frontend: HTML, CSS, Bootstrap

## 3. Core Entities
1. Users
2. Categories
3. Suppliers
4. Products
5. SupplierProducts
6. PurchaseOrders
7. PurchaseOrderItems
8. StockMovements

## 4. Database Name
InventoryDB

## 5. Design Principles
- Use primary keys to uniquely identify records.
- Use foreign keys to maintain relationships.
- Apply appropriate constraints to protect data integrity.
- Normalize relational tables to reduce redundancy.
- Maintain stock movement history.
